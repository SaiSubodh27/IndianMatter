About this tool

This web app accepts CIF (Crystal Information File) inputs and runs them through a multi-stage feature extraction and classification pipeline for solid-state electrolyte (SSE) research.

Pipeline stages
${[ ['CIF Parse','Extracts lattice params, space group, atomic sites from raw CIF text'], ['cif_v1–v3','Structural feature sets derived from crystal geometry and symmetry'], ['Magpie','Compositionally-averaged elemental property features (matminer)'], ['Composition','Manual composition-level features: electronegativity, radii, valence'], ['Ensemble','LightGBM + XGBoost + CatBoost + MLP soft-voting classifier'], ['VGNN','Variational Graph Neural Network for phonon-derived scalars (Ea*, ZPE*, σ*)'], ['Classify','8-class material class assignment with confidence distribution'], ].map(([s,d])=>`
${s} ${d}
`).join('')}
Backend integration

The frontend is ready to call a FastAPI backend at /api/analyze. Use backend.py as the integration point to plug in your real pretrained models. All session data is saved to CSV on export.
